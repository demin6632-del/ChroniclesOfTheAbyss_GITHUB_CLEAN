# Хроники Бездны — Android

Android WebView-обёртка для текущего `game.html`.

Игровой HTML-файл помещён в `app/src/main/assets/game.html` без изменения содержимого.

## Сборка

GitHub Actions: Actions → Build APK → Run workflow.

После успешной сборки: Artifacts → ChroniclesOfTheAbyss-debug-apk.

Локально: `gradle assembleDebug` (требуется Gradle 8.11.1 и JDK 17).
